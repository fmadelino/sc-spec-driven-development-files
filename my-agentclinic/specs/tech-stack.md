# Technology Stack

- **Language and runtime:** TypeScript on the server.
- **Web framework:** Fastify, recommended for a lightweight, TypeScript-friendly
  server foundation.
- **Database:** SQLite for persistent clinic data.
- **Client experience:** A modern-browser-compatible interface for agents and
  staff, with dashboard access to clinic services.

Keep the initial architecture small and reliable. Revisit framework or database
choices only when product needs provide a concrete reason.
